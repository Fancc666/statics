# 类与对象

对象：封装、继承、多态。

## 封装

封装属性和行为；进行权限控制。

三种权限

- public公共
- protected保护
- private私有

**struct与class区别**

都可以用来写类。但是默认的访问权限不同，struct默认权限为`公有`，而class是`私有`。

私有化优势：控制读写权限；检验数据有效性。

```cpp
// 对象初始化和清理
class Person
{
public:
    Person(){ // 构造函数在生成实例时调用
        // 可以有参数 无返回值 可以重载
    }
    ~Person(){
        // 无参数无返回值
        // 析构函数销毁时调用
    }
};
```

构造函数分类

- 按照参数
    - 有参
    - 无参
- 按照类型
    - 普通
    - 拷贝

调用方法：括号法、显示法、隐式转换法。
