# 内存四区

- 代码区：存放代码
- 全局区：全局变量、静态变量、常量
- 栈区：编译器管理的变量
- 堆区：程序员管理的变量

**意义：不同区域有不同的生命周期，可以给我们更大的灵活性。**

## 代码区

在程序运行之前就存在了，放置的是从“可执行文件”来的二进制机器码。

**特点：共享（多个副本运行时只保留一套机器码）、只读。**

## 全局区

存放全局变量和静态变量，包含一个常量区。程序执行完毕后，操作系统管理数据的释放。

1. 全局区里“没有”：局部变量，const修饰的局部变量。
2. 全局区里有：全局变量，静态变量，static关键字，常量，const修饰的全局变量。

## 栈区

编译器分配和回收，存放函数的参数值和局部变量。

**注意：不要返回局部变量的地址，因为会被重新分配。**

```cpp
int * func(int b){
    int a = 10;// 栈区，函数执行完会被释放
    // return &a;// !!!不要返回局部变量的地址
    // return &b;// !!!不要返回参数的地址
}
```

## 堆区

程序员利用`new`在堆区开辟内存。程序员手动管理释放空间。

释放内存使用`delete`关键字。如果是释放数组，那就用`delete []`。
