# 重力加速度测量实验

## 实验器材
一节PVC管（或铁架台）、细绳、燕尾夹、重物（或小球）、卷尺、手机秒表（或停表）

## 实验过程
1. 固定PVC管
2. 用燕尾夹在PVC管上固定细绳
3. 在细绳上固定重物
4. 测量固定点到重物重心距离$l$
5. 将细绳拉开一个较小摆角
6. 用秒表多次测量一个周期所用时间$T$
7. 收拾器材

## 实验数据
摆长：$l=0.58m$

| 次数 | 一个周期时长(s) |
| :--: | :--: |
| 1 | 1.61 |
| 2 | 1.51 |
| 3 | 1.51 |
| 4 | 1.46 |
| 5 | 1.58 |
| 6 | 1.51 |
| 7 | 1.60 |

平均周期：$T=1.54s$

根据单摆周期公式

$$T=2\pi \sqrt{\frac{l}{g}}$$

重力加速度为

$$g = \frac{4\pi^2l}{T^2} $$

代入数据得

$$g=9.65m/s^2$$

## 实验结论
根据百度搜到的天津重力加速度大小为$g=9.80m/s^2$，本次实验误差在允许范围之内。
